## Подтверждённые исходные проблемы и исправления

1. Кнопки «Пропустить задание» немедленно вызывали существующие обработчики в `#qstage`, `#tstage` и `#stage` (обычные задания, таблица умножения, запись столбиком, тренировка ошибок/слабых тем/контрольный обзор).
2. Теперь нажатие на **реальную кнопку пропуска текущего активного вопроса** сначала показывает диалог с пояснением, что отметка о пропуске необратима. Кнопка «Вернуться к заданию» и Esc сохраняют исходный вопрос, результаты, фокус и состояние; подтверждение вызывает исходный обработчик ровно один раз.
3. Перед выполнением подтверждённого пропуска проверяются тот же профиль, ID попытки, ссылка на тот же объект вопроса, счётчик выполненных заданий и наличие активной кнопки. Устаревший диалог не должен пропускать уже заменённую задачу.
4. Диалог выхода теперь явно предупреждает: **«Выйти и удалить попытку»** уничтожит незавершённый черновик. Действие «Остаться в тренировке» безопасно и предлагается первым. Сама существующая модель намеренного выхода без сохранения не менялась.
5. «Начать заново» при предложении восстановления теперь требует **второго подтверждения** с проверкой актуального профиля и ID сохранённого черновика. Отмена не удаляет черновик.
6. Общий диалог не допускает повторного выполнения действия при двойном нажатии. Добавлены явные focus-visible и адаптивные стили для узких экранов, с поддержкой reduced motion.

**Не менялись:** генераторы, задания, правильные ответы, штрафы и награды, XP/монеты, владеемые предметы, структура профиля, backend, production.
