Дата: 23 ноября 2026. PR #131. Только `refactor/route-vue-actions-from-7c14ce9`. `main`, production и backend не менять.

## Фактический срез

Статическая проверка `index.html` выполнена через GitHub Actions `Test-only legacy Vue migration anchors`, коммит `1ea685a`. Регулярное выражение по прямым `module.mount*` обнаружило **41 обращение к 36 различным именам mount-функций**. Это НЕ подсчёт всех Vue-компонентов или всех вызовов: некоторые mount-функции вызываются через другие переменные, а строка с таким именем может быть в старом fallback.

Из просмотренных точек:
- `mountAppHeader`: 2 обращения; объект `actions` из семи обработчиков (`home`, `profile`, `wallet`, `shop`, `data`, `journal`, `leaders`).
- `mountQuickTrainerSetup`: 1 обращение; общий `run(action)` маршрутизирует `choice`, `smart`, `start`, `train-all`, `home`, с защитой от неактуальной сессии и открытого диалога.
- `mountQuickTrainerResult`: 1 обращение; `again`, `home`, `returnToPlan` должны отбрасывать устаревшие нажатия и сохранять выбранные настройки.
- `mountTrainingPlan`: 1 прямое обращение, динамические обработчики редактирования и запуска пунктов; **не переносить** совместно с быстрым тренажёром без отдельного аудита.
- Отдельные источники действий ещё есть у генераторов школьных заданий, журналов попыток, магазина, профилей и учительских экранов. Их бизнес-логика остаётся в HTML до самостоятельных этапов.

## Граница v271

Новый `assets/ui/legacy-vue-actions.js` — независимый UMD-модуль без доступа к DOM, хранилищу, сети, монетам или XP; принимает только внедряемые обработчики и проверяющие функции. Переводятся только шапка, настройка и результат быстрого тренажёра. Старые inline `fallbackActions` сохраняются в `index.html` без изменения вычислений и UI.

Обязательные тесты: Node-контракты без DOM; PWA v270→v271 с проверенным скриптом в SW-кеше; Playwright 390/1280 (Enter, Space, Back/Forward, offline F5, сохранение результата/награды без дублей, возврат в тренажёр, блокировка обоих необязательных модулей), плюс полная PWA-регрессия и offline-проверки 320/390/768.

Отдельно проверяется, что неверный SHA256 7,6 МБ HTML останавливает патч до любых записей; после успешного CI проверенные `index.html` и `sw.js` может опубликовать только GitHub Actions на текущую вершину этой же тестовой ветки.

Это выделение контроллеров Vue, а не полный перенос интерфейса или готовность backend. PR #131 остаётся draft; merge и деплой не выполнять.
