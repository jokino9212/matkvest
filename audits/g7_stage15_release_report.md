## 4. Остаточные риски и границы тестирования

- Старый уже открытый v39 HTML **не может получить задним числом** обработчик `controllerchange`, впервые добавленный в v40. Проверка реального наследуемого поведения должна подтверждать получение новой версии при обычной **онлайн-навигации**; мгновенное автообновление бесконечно открытой старой вкладки нельзя гарантировать.
- Невозможно принудительно обновить полностью офлайн-устройство до подключения к сети.
- Существующая незавершенная попытка из старого HTML v39, если тот не умеет сохранять draft, не может быть абсолютно гарантированно восстановлена при переходе. Не трогать реальные пользовательские хранилища и не утверждать обратное.
- Симуляция пользовательских XP/coins/collection в release-тесте использует изолированное синтетическое хранилище; это не независимый полный тест каждого типа реального профиля.
