## 3. Единая художественная грамматика

- Эстетика: современный, динамичный игровой collectible, 2.5D / semi-vector, насыщенный, **не детсадовский и не «эмодзи на кружке»**.
- Для всех: SVG 512×512 `viewBox`, узнаваемый силуэт, выразительная эмаль, объёмный материал, один основной и один вспомогательный сюжет, мягкий свет сверху слева, контролируемые блики, поля под glow и рамку, читаемость на 48px.
- **Не один шаблон медали с заменой буквы.** Сочетать медальоны, гербы, шестиугольные знаки, трофеи, кристаллы и ленты, сохраняя общий характер контуров/света.
- Редкость передавать цветом, орнаментом, сложностью рамки, видимой подписью редкости, но не менять имеющиеся значения `rarity`.
- Надпись/число использовать только там, где они сами являются смыслом (π, √, Σ, ÷, 4, 5, 1000, уравнение); все остальные должны быть самостоятельными изображениями.
- Никаких внешних CSS/JS/картинок внутри SVG; уникальные ID градиентов; безопасная оптимизация SVG без визуальной деградации.

## 5. Обязательный Gate для каждого изображения

1. XML/SVG без script, `onload`, `foreignObject`, внешних изображений/URI.
2. Правильный `viewBox` и безопасный экспорт.
3. Видимая часть иллюстрации не крошечная на холсте; не обрезаны блики, тени, подписи.
4. Читабельно на 32/48px, красиво на 160/512px, без мыла и сломанной типографики.
5. Пропорции и цвет согласованы с одобренными тремя примерами; каждый мотив визуально отличим.
6. У всех 16 сохранены original ID/rarity/price/earned rules. Regression Gate проверяет покупки, экипировку и достижение отдельно.
7. Проверка картинки не считается достаточной без проверки реальной карточки и fullscreen после интеграции.
