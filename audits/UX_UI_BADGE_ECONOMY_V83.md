## Проверенная экономика
- Обычный правильный ответ: **3 монеты**.
- Деление столбиком (type=column): **5 монет**.
- Бонус за серию каждого пятого правильного ответа, не кратного 10: **+5 монет**.
- Бонус за серию каждого десятого: **+15 монет**.
- Прочие бонусы в обучающих блоках могут добавлять монеты; это **не фиксированная ставка**, не считать время накопления по 3 монеты без учёта других наград.
- Все семь старых покупаемых значков стоят 55–125 монет, 9 достиженческих не продаются.
- У новых значков есть требование минимального уровня; реальные уровни рассчитываются из XP через штатную функцию.

### Проверенная покупка
В staging-тесте покупка `bd_comet` добавляет правильный item ID в инвентарь, а поле исторических расходов `state.shopStats.spent` увеличивается **ровно на 160**. Проверка чистого изменения `state.coins` дала **77**, поскольку сохранение может одновременно начислить наградные монеты через штатные достижения (в этом тесте разница +83). Это **не скидка**: тест должен сверять расходный ledger и не требовать равенства только по разнице балансов. Прямое списание в `buyShopItem` — `state.coins -= item.price`.
