## Автообновление при будущих публикациях

- Новая регистрация Service Worker периодически вызывает `registration.update()`, при возвращении к видимой вкладке также проверяет обновление.
- Смена контролирующего SW выполняет `mk872PersistDraft()`, если есть незавершённое занятие, и затем `location.reload()`. Если запись черновика не удалась, перезагрузка откладывается для сохранения данных.
- `sw.js` содержит `APP_BUILD_HASH` — SHA-256 HTML. Предусмотрен автоматический синхронизатор `.github/workflows/matkvest_pwa_sync.yml` при будущих изменениях `main/index.html`.
- Dry-run синхронизации пройден: https://github.com/jokino9212/matkvest/actions/runs/41817684638.

**Ограничения:** нет мгновенного обновления без подключения к интернету; если нельзя безопасно записать попытку в хранилище, обновление не должно приводить к потере данных. Workflow синхронизации начнёт работать на `main` только после публикации файла в этой ветке.
