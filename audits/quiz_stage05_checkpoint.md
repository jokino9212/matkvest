## Подтверждённые симптомы однообразия
Доля **уникальных текстов условия** из 80 генераций на уровнях 0 / 1 / 2:
- `angles`: **13% / 1% / 51%** — средний уровень генерирует практически один и тот же текст;
- `charts`: **11% / 31% / 29%**;
- `frac_shapes`: **10% / 21% / 23%**;
- `frac_parts`: **25% / 26% / 50%**;
- `frac_ray`: **25% / 24% / 49%**;
- `frac_common_lcm`: **36% / 40% / 78%**;
- `dec_to_common`: **14% / 14% / 71%**.

Эта метрика отражает только **текст после удаления HTML/SVG**, а не полное задание. Например, в `angles` на среднем уровне применяется меняющийся рисунок транспортира `g5ProtractorSvg(a)`: текст задания неизменен, но сама картинка и правильная градусная мера варьируются. Поэтому 1% уникальных текстов **не доказывает** 1% уникальных задач. Для `charts` также требуется включить в идентичность графику, а для тем с одинаковым текстом — ожидаемый ответ и подтип. Низкое текстовое разнообразие — повод для приоритетной проверки, но не окончательное доказательство повторов.

## Методологические ограничения
- При последующем просмотре исходников обнаружены различные ветки `mk5Fractions` и базового `g5DonorQuestion`, включая задачи с динамической SVG-графикой. Поле `templateId` почти везде = `base`: на этом этапе нельзя делать вывод, что у тем реально по одному шаблону. Нужно анализировать исходный `g5DonorQuestion`/ветвления и нормализовать семантические типы текста.
- `p90` — наивный максимум целых чисел, извлечённых из строки. Для заданий с перечнем углов или математическими HTML-формулами он может склеивать цифры и **не является мерой педагогической сложности**; приоритет — реальная сложность операции, количество шагов, диапазоны чисел, доли многошаговых задач.
