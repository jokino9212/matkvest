## Точечная правка v69

Файл `audits/ui_stage19i_patch.py` изменяет **только** HTML-слой доступа к существующему `#modal`, с жёстким контролем SHA исходной v68. Добавлены:
- Семантика диалога и название через видимый заголовок; понятная подпись у кнопки закрытия.
- Перевод фокуса внутрь при открытии; возврат к исходному элементу после закрытия.
- Кольцевая навигация Tab / Shift+Tab внутри окна; Esc использует исходный `closeModal()`.
- Исключение для вложенных диалогов справки и безопасности тренировок, чтобы не перехватывать их обработчики.
- Видимый фокус заголовка, без изменения предметной логики.

**Не изменены:** математические генераторы, ответы, переходы между ступенями, XP, монеты, магазинная экономика, инвентарь, профили, backend и `main`.
