## Исправлено в v62
1. На страницах 3, 5, 6, 7 и 8 классов, где 20+ тем, появился компактный **поиск тем**, включая русские поисковые запросы, поиск по названию темы и названиям разделов.
2. При вводе фильтруются только карточки, пустые группы разделов скрываются, отображается количество найденных тем. Есть сообщение об отсутствии результатов и кнопка «Очистить».
3. В 7-м и 8-м классах добавлены быстрые ссылки «Алгебра», «Геометрия», «Вероятность и статистика». Нажатие прокручивает до соответствующего раздела.
4. На ширине 320 px верхнее меню больше не занимает три ряда: высота **164 → 124 px**, без потери профиля, монет, уровня или меню.
5. Сохранены родные HTML-кнопки учебных тем с теми же onclick-обработчиками. При очистке фильтра все исходные темы возвращаются.
6. Поиск адаптирован к клавиатуре, экранным дикторам (aria-label, role=status), маленькому экрану и prefers-reduced-motion.
7. CSS и JS добавлены в index.html только точечным проверяемым патчем audits/ui_stage19c4_patch.py с исходным SHA; sw.js синхронизирован по fingerprint.

Учебные генераторы, содержимое теории и заданий, правильные ответы, попытки, блокировки этапов, XP, монеты, магазин, данные и backend не изменялись.
