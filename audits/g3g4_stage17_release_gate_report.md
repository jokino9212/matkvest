## Почему релизную ветку создали отдельно

Исходная audit-ветка опережала `main` на 197 коммитов; там много исходников проверок и отчётов, не предназначенных для production. Для clean release создан новый commit на базе **точного** `main` SHA с использованием Git blob из уже прошедшего Gate. Сравнение GitHub `main...release/stage17-v50-20261105` подтвердило **1 коммит и ровно 2 изменённых файла**. `manifest.webmanifest` побайтно совпадает с production. Патчи, скрипты, JSON-отчёты и CI-эксперименты в чистый релиз не входят.
